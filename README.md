Instrucciones para utilizar el programa

1. Ingresar vehículo

Seleccione la opción 1.

El programa solicitará la placa del vehículo. La placa debe tener el formato:

P###LLL

Por ejemplo: P123XYZ.

Después deberá ingresar la fila y columna donde desea estacionar el vehículo. Las posiciones válidas están entre 1 y 8.

Finalmente, el programa solicitará el monto entregado. La tarifa es de Q10.00. Si el monto es mayor a Q10.00, el programa calculará y mostrará el cambio.

El sistema verifica que la placa sea válida, que no esté registrada anteriormente y que el espacio seleccionado esté disponible.

2. Retirar vehículo

Seleccione la opción 2.

Ingrese la placa del vehículo que desea retirar. El programa buscará la placa dentro del estacionamiento.

Si el vehículo existe, se liberará el espacio y se mostrará la fila y columna donde se encontraba.

El retiro del vehículo no modifica los ingresos acumulados.

3. Mostrar estacionamiento

Seleccione la opción 3.

El programa mostrará el estado actual del estacionamiento, indicando los espacios libres y ocupados.

Los símbolos utilizados son:

= : vía exterior
E : entrada
S : salida
L : espacio libre
A : automóvil

Al finalizar se mostrará la cantidad de espacios libres y ocupados.

4. Buscar vehículo por placa

Seleccione la opción 4.

Ingrese la placa del vehículo que desea buscar.

Si el vehículo se encuentra dentro del estacionamiento, el programa mostrará su fila y columna. Si no existe, se mostrará un mensaje indicando que el vehículo no fue encontrado.

5. Mostrar ruta más corta

Seleccione la opción 5.

El programa calculará las dos rutas posibles entre la entrada y la salida:

Sentido horario.
Sentido antihorario.

Se mostrará la distancia de ambas rutas y se indicará cuál es la ruta recomendada. Si ambas tienen la misma distancia, se indicará que cualquiera puede utilizarse.

6. Mostrar ingresos

Seleccione la opción 6.

El programa mostrará:

Cantidad de vehículos cobrados.
Tarifa por vehículo.
Total de ingresos acumulados.

La tarifa por cada vehículo registrado es de Q10.00.

7. Salir

Seleccione la opción 7 para finalizar el programa.

Al cerrar el programa, los datos registrados durante la ejecución no se conservarán, ya que el sistema no utiliza una base de datos ni almacenamiento permanente.
